# Incident Report Form Builder

Fill out a structured incident report with root cause analysis and corrective actions, then print as a formatted document.

## Features
- Six structured sections: incident info, persons involved, 5W1H description, immediate actions, 5 Whys root cause table, and corrective action tracking
- Severity selector: Near Miss / Minor / Moderate / Major / Critical with color coding
- 5 Whys analysis rows (up to 5) with add/remove controls
- Corrective actions table with responsible party, target date, and status dropdown
- Form auto-saves to localStorage on every keystroke; print-friendly layout via browser print dialog

## Usage
Fill in each section from top to bottom. Select a severity level, add root cause "Why" rows as needed, and create corrective action rows with owners and target dates. Click Print Report to open the browser print dialog with a clean, print-optimized layout. Your form is automatically saved and restored on page reload.
